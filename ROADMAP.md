# Roadmap

Order of work. Each step is approved by Hudson before it starts.

1. **Foundation** (done: sign-in, access rules, launcher, people and access screens): Vercel project + Neon, Better Auth sign-in, users / groups / grants / share links, app registry (one list of every app: name, icon, URL, native or external, who can see it), public homepage, signed-in launcher, admin for invites and access, shared UI primitives.
2. **Gyfte** (gift lists): lists per person for Christmas and birthdays, links, sizes and colors, parents manage kids' lists, claims set per list (Off, Named, Anonymous; the person a list is for never sees them), family group sharing. Import and clean up the 2020-2025 Google Sheet. Done: lists and items, sharing and claims, bulk add, spreadsheet import. Done also: groups (group > year > lists) with a sample family and View as. Done also: family link with "This is me". Done also: kids under parents with joint lists. Done also: import into a group with who-is-who and kid splitting. Done also: the look (Editorial OS) and sign-in returning to the list you opened. Next, in order: Hudson runs the real import; everyday flow (My list, Family, I'm getting, connecting name-only imported lists to accounts (done), request to join with email approved by Hudson: done); turn off the family link once everyone has an account; request-a-group for non-admins; personal sign-in links as their own people with one or more parents and joint lists (then the real 2020-2025 import, splitting the joint tab); photos (upload or image link); automatic link previews. Later: list/grid view, drag to reorder, Chirk gift-exchange link, screenshot import.
3. **Microsites and presentations:** hosted pages at stable URLs, private, group-shared or public link, listed in the launcher.
4. **Sticky notes:** rebuild of the lovewillwin version (handover pack pending).
5. **Songwriting:** rebuild, multi-user. Owned songs, collaborators, version history; no live co-editing until there's a real need.
6. **Trip planner:** design from Hudson's real trip Sheets first. Group trips, itineraries, reservations, costs.
7. **Fitness** and **nutrition:** replace Fitbod and calorie tracking. Private by default, exportable.
8. **Apartment watcher:** rebuild with a separate scheduled worker.

External links in the launcher from day one: **Chirk** (chirk.fyi) and **Crewmaxxing / CMX**.
